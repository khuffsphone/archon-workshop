# Part 1 target platform

Part 1 targets the **web browser** only.

Use:
- React
- Vite
- browser-safe asset loading
- browser-safe audio handling
- CSS or existing web styling

Do not:
- start React Native
- start Expo
- introduce mobile-only platform APIs
- redesign the project around touch-first mobile behavior

Responsive layout is fine.
Mobile packaging is out of scope for Part 1.
