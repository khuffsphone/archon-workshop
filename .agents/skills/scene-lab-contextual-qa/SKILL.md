# Scene Lab Contextual QA

Use this skill for scene presets, slot assignment, contextual approval, compare flows, missing-slot review, screenshots, and review sheets.

## Goals
- turn Scene Lab into a proof station, not a fake demo
- allow approval in context, not only from isolated thumbnails

## Required presets
- Board State
- Combat Mockup / Combat FX Test
- Spell Cast Mockup
- Menu Screen
- Codex Screen
- Endgame Screen
- Audio Test

## Required review actions
- approve from scene
- reject from scene
- compare approved vs candidate
- compare multiple candidates
- attach review notes
- export screenshot
- export review sheet with asset ids, toggles, and timestamp

## QA principles
- missing slots must be visible
- readability must be testable in light, dark, and neutral conditions
- speed and contrast issues must be taggable

## Output contract
Return:
- presets added or upgraded
- slots supported
- review actions working
- screenshot/review-sheet proof
